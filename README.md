# Shawarma Bar — сайт-визитка

Одностраничный сайт кафе быстрого питания **Shawarma Bar**
(Волгоград, Комсомольская улица, 18; восточная кухня, шаверма и донер).

- **Живая ссылка:** https://iluuua.github.io/vlg-shawarma-bar/
- **Карточка в Яндекс Картах:** https://yandex.ru/maps/org/shawarma_bar/243195672214/
- **Телефон:** +7 (904) 409-63-71
- **Часы работы:** ежедневно 10:00 – 22:00 (без перерыва и выходных)

## Что на сайте

Обложка с рейтингом, блок «Почему сюда возвращаются», меню из 4 разделов
(27 позиций с ценами), галерея из 8 фотографий, 6 отзывов гостей, контакты
с картой и часами работы. Разметка Schema.org (`FastFoodRestaurant`),
`robots.txt` и `sitemap.xml` — в комплекте.

## Откуда данные

Всё содержимое — из карточки заведения в Яндекс Картах (выгрузка от 10.08.2026,
`_vlg-sitekit/data/shawarma-bar.json`):

- **меню и цены** — раздел меню карточки (27 позиций: стритфуд, закуски, напитки, соусы);
- **фотографии** — фотогалерея карточки, кадрированы без ретуши;
- **отзывы** — реальные отзывы гостей с оценкой 5; поправлены только опечатки
  и убраны эмодзи, смысл не менялся;
- **проценты в блоке «Отзывы»** — доли положительных упоминаний по аспектам
  Яндекс Карт (атмосфера 45/46, еда 258/329, кофе 8/11, мясо 113/159,
  чистота 19/27, шаверма 113/169);
- **рейтинг** — 4,8 при 608 оценках, 366 отзывов; награда «Хорошее место 2026».

Ничего не придумано: блюда, цены, часы, телефон и соцсети — только из карточки.

## Открытые вопросы к владельцу

1. **Wi-Fi.** В карточке Яндекс Карт Wi-Fi отмечен как «есть», но в отзыве от
   22.05.2026 гость пишет, что Wi-Fi нет. На сайте Wi-Fi **не упоминается** —
   подтвердите, работает ли он, чтобы добавить.
2. **Цены в зале и в доставке различаются.** На фото меню-борда в зале старые
   цены (например, шаурма мясная 300/220 ₽), в карточке доставки — 300–450 ₽.
   На сайте — цены из карточки, с оговоркой «уточняйте на кассе».
   Пришлите актуальный прайс зала — обновим.
3. **Бизнес-ланч 260 ₽ и завтраки** взяты из карточки. Подтвердите, что
   предложение действует, и пришлите состав — можно раскрыть подробнее.
4. **Доставка.** В карточке указаны Яндекс Еда и Delivery Club; на сайте назван
   только Яндекс Еда (Delivery Club больше не работает). Если есть свой сервис
   доставки или заказ через Telegram-бота @shawabar_bot — дайте ссылку.
5. **Логотип.** В карточке логотипа нет, поэтому в шапке только название,
   а иконка сайта сделана из фотографии. Пришлите файл логотипа — поставим его.
6. **Год основания.** На вывеске у входа читается «EST. 20..», разобрать
   уверенно не удалось, поэтому на сайте года нет. Скажите год — добавим.
7. **Соцсети и свой сайт.** В карточке есть только Telegram-бот @shawabar_bot.
   Если есть ВКонтакте / собственный сайт — добавим в контакты.

## Как пересобрать

```bash
cd /Users/ilua/Documents/ilua-system/projects
python3 _vlg-sitekit/build.py vlg-shawarma-bar          # index.html + robots.txt + sitemap.xml
python3 _vlg-sitekit/check.py vlg-shawarma-bar shawarma-bar
_vlg-sitekit/deploy.sh vlg-shawarma-bar "Сайт Shawarma Bar, Волгоград, Комсомольская улица, 18"
```

Правится только `content.json` — HTML генерируется скриптом кита
`_vlg-sitekit/build.py`, стили и скрипт копируются оттуда же.
Исходники фотографий лежат в `img/raw/` и в репозиторий не попадают.
